
# FinOps Tagging Model

Recommended minimum tags:

| Tag | Purpose |
|---|---|
| `Environment` | dev, hml, prd, sandbox |
| `Owner` | accountable team or cost owner |
| `Application` | product/application identifier |
| `CostCenter` | billing allocation |
| `ManagedBy` | terraform, manual, vendor |
| `Criticality` | low, medium, high, mission-critical |

A repository that exposes tag strategy demonstrates cost governance, not just Terraform syntax.

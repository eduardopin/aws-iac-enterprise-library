# Discussion Welcome Draft

Welcome to the AWS IaC Enterprise Library discussions.

This repository is a set of small Terraform building blocks, matching examples
and engineering guidance for AWS infrastructure. Discussions are a place to
compare implementation choices before turning a proposal into a focused issue
or contribution. Please keep examples generic and do not include credentials,
account IDs, internal hostnames or customer details.

To start the conversation:

1. Which module or example did you try, and what was easy or unclear?
2. Which security, reliability or cost guardrail would make a module easier to
   review in your environment?
3. Which item in `docs/community/GOOD_FIRST_ISSUES.md` would you like to work on,
   or what similarly small improvement should be added?
